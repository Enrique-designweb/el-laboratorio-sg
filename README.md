# El Laboratorio SG - Corporate Website

## 📝 Project Overview

A modern corporate website developed for a laboratory. The project emphasizes clean design, fast performance, and an intuitive user interface using Tailwind CSS.

## 🛠️ Tech Stack

- **Framework:** Next.js, React
- **Styling:** Tailwind CSS
- **Hosting:** Netlify
- **Performance:** Priority Hints
- **Icons:** Lucide

## ✨ Key Features

- Modern and minimalist UI.
- Fully responsive design.
- Cart Functionality integration (if applicable).
- Optimized for fast loading and SEO.
